# KRX Investor Flow Research

외국인·기관 수급이 **이후** 주가 수익률을 예측하는지 검증하는 독립 연구입니다.

## 1차 파일럿
- KOSPI/KOSDAQ 보통주 중 대표 표본(기본 30종목, 시가총액 상위 기반)
- 2026-01-01 ~ 2026-10-31 자료 (종료일은 실행일 이전으로 제한)
- 5/10/20 거래일 외국인·기관 순매수 **수량** 합계의 부호로 A/B/C/D 분류
- 신호일 이후 5/10/20 거래일 종가 수익률. 진입 가능성을 감안한 다음 거래일 종가 기준 수익률도 별도 저장
- 결과: 원시 패널 CSV, 그룹별 통계 CSV, 진단 JSON
- 탐색적 파일럿이며 전종목 결과나 거래비용 반영 백테스트가 아닙니다.

## 실행
Actions > Investor Flow Pilot > Run workflow. 결과는 workflow artifacts에 업로드됩니다.

데이터: pykrx를 통한 KRX 공개 데이터. 수집 실패/결측은 0으로 채우지 않고 제외·기록합니다.
KRX 로그인 함수는 별도로 유지하며 자격 증명이 설정되지 않으면 공개 조회 모드로 실행합니다. 로그인 성공 여부를 추정하지 않습니다.
